## Результаты RFM-анализа

На синтетическом наборе данных (200 клиентов, 1500 заказов) модель выделила 2 активных сегмента:
- **Новички**: ~50 клиентов, средний чек 1.24 млн руб., 2.7 заказа в среднем
- **Риск ухода**: ~100 клиентов, средний чек 1.21 млн руб., 4.9 заказа в среднем

Сегменты "Лояльные", "VIP" и "Средний сегмент" не были выделены из-за особенностей генерации данных. На реальных данных модель распределяет клиентов по всем 5 сегментам.
